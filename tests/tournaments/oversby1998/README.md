# Oversby Autumn 1998 Tournament Test

This test suite exercises a deterministic subset of the Oversby Autumn
1998 tournament archive.

## Parameters
- Standard: `94 Draft`
- Core size: `8000`
- Max processes: `8000`
- Cycles: `80000`
- Max warrior length: `100`
- Minimum distance: `100`
- Rounds: `200`
- Seed: `-f`

## Warriors
The regression fixture uses the archived round 1 warriors already
present in the repository:
- `moore.red`
- `Schmidt.red`
- `Macrae.red`
- `pihlaja.red`
