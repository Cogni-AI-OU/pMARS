# EBS ICWS Qualification Tournament (Nov 1991)

The Electronic Branch Section held an ICWS Qualification Tournament in November 1991 with the top warriors advancing to the 1991 ICWS Tournament.

## Tournament Parameters

- **Standard:** ICWS'88
- **Core Size:** 8192
- **Cycles:** 100,000
- **Processes:** 64
- **Scoring:** 3 points per win, 1 point per tie
- **Format:** One-on-one round robin with self-fights, 6 rounds per match
