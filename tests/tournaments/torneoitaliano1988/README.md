# Primo Torneo Italiano di Core Wars (Oct 1988)

The First Italian Core Wars Tournament was held on 7th–22nd October 1988 at the *Futuro Remoto* exhibition in Naples. [Lux 2](https://corewar.co.uk/ti1988/lux2.red) by Luca Crosara claimed first place and advanced to the [Third ICWS Tournament](https://corewar.co.uk/icwt1988.htm).

## Historical Parameters
- **Standard:** ICWS'86 (simulated with `pmars -8`)
- **Core Size:** 8192
- **Max Processes:** 64
- **Cycles:** 50000
- **Rounds:** 200 (Matches were likely round-robin, but for testing we can simulate pairwise or a mini-league)

## Warriors
Available warriors from the tournament:
- [Lux 2](../../../warriors/tournaments/ti1988/lux2.red) by Luca Crosara (1st Place)
- [Sturm und Drang](../../../warriors/tournaments/ti1988/sturmunddrang.red) by G. Ciraolo & L. Pancani (2nd Place)
- [Panca 1](../../../warriors/tournaments/ti1988/panca1.red) by L. Pancani & G. Ciraolo (3rd Place)
