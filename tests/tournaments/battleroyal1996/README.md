# Battle Royal (April 1996)

Organized by John K. Lewis, the Battle Royal was a limited-process tournament (8 processes) designed to break the strategy deadlock on multi-warrior hills.

## Tournament Parameters

- **Coresize:** 8000
- **Max Processes:** 8
- **Cycles:** 80,000
- **Rounds:** 200
- **Instruction Set:** ICWS'94 Draft
