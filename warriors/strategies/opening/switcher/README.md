# P-Switcher

**P-space** was proposed as an extension to the Core War Standard to allow warriors to store results and other information between rounds. A **p-switcher** uses p-space to switch between two or more different components / strategies depending on the results of one or more previous rounds.

A state-based p-switcher is a warrior that behaves like a finite state machine: each state corresponds to a strategy, and the warrior switches strategy based on the previous round's result (win, loss, or tie).

Source: [corewar.co.uk/switcher.htm](https://corewar.co.uk/switcher.htm)
