# Endgame Strategy

Some warriors are only designed to damage or stun the opponent during the midgame, then switch to an endgame strategy to finish the opponent off.

- [Clear](clear/README.md): A core-clear wipes memory with deadly `DAT` bombs. Some clears also have a `SPL` wipe to stun the opponent. Clears are often used by scanners and bombers to wipe memory at the end of the game.
