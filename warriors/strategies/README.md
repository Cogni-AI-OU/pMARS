# Core War Strategy Guide

A variety of strategies have evolved for Core War, each with its own strengths and weaknesses. Warriors often include up to three distinct stages: an opening strategy, a midgame strategy, and an endgame strategy.

## [Opening Strategy](opening/README.md)

An opening strategy is used by some warriors to gain an advantage during the first few cycles before moving on to the midgame. The code for the opening strategy is normally run once and then discarded.

- [Quickscan](opening/quickscan/README.md)
- [Bootstrap](opening/boot/README.md)
- [Decoy Maker](opening/decoymaker/README.md)
- [P-Switcher](opening/switcher/README.md)
- [Handshake](opening/handshake/README.md)

Some warriors are only designed to damage or stun the opponent during the midgame, then switch to an endgame strategy to finish the opponent off.
