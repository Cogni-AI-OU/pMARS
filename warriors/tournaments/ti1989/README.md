## Tournament: Secondo Torneo Italiano di Core Wars (Nov 1989)

The **Second Italian Core Wars Tournament** was held in Florence in late November 1989 by the ICWS Italia. Hypray by Francesco Botta claimed first place followed by UMACCP and Kili.

### Tournament Settings
- **Standard:** ICWS'86
- **Coresize:** 8192
- **Cycles:** 50000
- **Processes:** 64
- **Entry Length:** 512
- **Rounds:** 200
