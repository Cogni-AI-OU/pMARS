# IRC Mini Tournament #03 - Sunday 16 March 2003

The third IRC speed redcoding tournament is hosted by Roy van Rijn. Played in a standard 8000 cell core, entries may only contain values of either -1, 0 or 1 in the compiled Redcode. This week, 7 players enter a total of 12 warriors, with Phil Thorne taking the #1 spot, closely followed by Mizcu.

## Details

- **Coresize**: 8000
- **Restriction**: Entries may only contain values of either -1, 0 or 1 in the compiled Redcode.
- **Duration**: 30 minutes
