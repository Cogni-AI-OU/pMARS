Reference: [KOFACOTO home page](http://www.koth.org/kofacoto/) | [Rules](http://www.koth.org/kofacoto/rules4.html) | [Results](http://www.koth.org/kofacoto/results4.html) | [Warriors](http://www.koth.org/kofacoto/warriors/round4)

## Rules

THE CIA HAS BEEN TAKEN HOSTAGE BY JEDIMPS!!

Your mission is to rescue the CIA (Anders Ivner's C I A stone) from the evil Jedimp army!

Your redcode, CIA, and a modified version of Jedimp will compete together in a 3-way multiwarrior battle.

- If CIA dies, you get 0 pts.
- If you die, you get 0 pts.
- If everyone survives, you get 1 pt.
- If you/CIA survive and Jedimp dies you get 10 pts.

Standard '94 parameters:
`pmars -d 100 -c 80000 -p 8000 -l 100`
