# Anton's Core War Tournament (Jul – Aug 1997)

Anton's Core War Tournament was organised by Anton Marsden and ran for three rounds in July / August 1997.

Original website: [https://corewar.co.uk/acwt.htm](https://corewar.co.uk/acwt.htm)

## Tournament Structure

### [Round 1: Sorting](round1/)
Writing a sorting program in Redcode. Programs were judged by size and speed.

### [Round 2: Beat Electric Head](round2/)
Design a warrior to beat [Electric Head](round2/electric.red) by Anton Marsden.

### [Round 3: Pretty Picture](round3/)
Write a program to display a pretty picture. Entries were judged purely on creativity.
