# Round 3: Pretty Picture

The objective of Round 3 was to write a Redcode program which draws a "pretty picture" (and perhaps animates it) on the screen.

## Rules

- Maximum code size: 100.
- Parameters: same as the '94 draft hill.
- The standard colours for warrior 0 are used: green for executing code, cyan for killed processes.
- Increments/decrements also make marks in the viewer.
- Judging was based purely on creativity.
