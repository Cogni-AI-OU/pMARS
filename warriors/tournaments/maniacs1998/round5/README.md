# Redcode Maniacs Tournament (1998) - Round 5 Warriors

This directory contains a selection of warriors from Round 5 of the Redcode Maniacs Tournament.

## Warriors

- **[Foggy swamp](./bezzi.red)** by Beppe Bezzi (1st place)
- **[Freight Train](./moore.red)** by David Moore (2nd place)
- **[Kitchen Sink II](./macrae.red)** by Robert Macrae (4th place)

## Tournament Rules (Round 5)

- Core size: 8000
- Max processes: 8000
- Cycles: 80000
- Max entry length: 100
- Min distance: 100
- Rounds: 200
- Instruction set: **Redcode '88 Standard**

## Results (Top performers)

1. Foggy swamp (Beppe Bezzi) - 4296 pts
2. Freight Train (David Moore) - 4257 pts
3. MyHeremPaper (John K Wilkinson) - 3700 pts
4. Kitchen Sink II (Robert Macrae) - 3599 pts
