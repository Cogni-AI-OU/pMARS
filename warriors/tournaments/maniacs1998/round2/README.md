# Redcode Maniacs Tournament (1998) - Round 2 Warriors

This directory contains a selection of top-performing warriors from Round 2 of the Redcode Maniacs Tournament (February 1998).

## Warriors

- **[LP and Feelin' Fine.](./wilkinson.red)** by John K Wilkinson (1st place)
- **[Snake Pit](./moore.red)** by David Moore (2nd place)
- **[Incisive](./macrae.red)** by Robert Macrae (3rd place)
- **[Beanbag](./kline.red)** by Paul Kline (4th place)
- **[Recycled paper](./bezzi.red)** by Beppe Bezzi (5th place)
- **[life is short](./planar.red)** by Planar (6th place)

## Tournament Rules (Round 2)

Round 2 was a **Low Process (LP)** challenge, strictly limiting the number of processes.

- Core size: 8000
- Max processes: 8
- Cycles: 80000
- Max entry length: 200
- Min distance: 200
- Rounds: 200
- Instruction set: Redcode '94 Draft

## Results (Top 5)

1. LP and Feelin' Fine. (John K Wilkinson) - 5104 pts
2. Snake Pit (David Moore) - 4714 pts
3. Incisive (Robert Macrae) - 4527 pts
4. Beanbag (Paul Kline) - 4467 pts
5. Recycled paper (Beppe Bezzi) - 3995 pts
