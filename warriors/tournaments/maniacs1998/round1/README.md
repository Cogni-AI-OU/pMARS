# Redcode Maniacs Tournament (1998) - Round 1 Warriors

This directory contains a selection of warriors from Round 1 of the Redcode Maniacs Tournament, held between January and April 1998.

## Warriors

- **[Tornado 4](./bezzi.red)** by Beppe Bezzi (1st place)
- **[Silver Talon 1.3](./edgar.red)** by Edgar (2nd place)
- **[No Ideas](./karonen.red)** by Ilmari Karonen (3rd place)
- **[traumatic smurf](./guenzel.red)** by Björn Günzel (4th place)
- **[Phantasm 50](./macrae.red)** by Robert Macrae (5th place)
- **[Funky Monks](./moore.red)** by David Moore (7th place)

## Tournament Rules (Round 1)

- Core size: 8000
- Max processes: 8000
- Cycles: 80000
- Max entry length: 50
- Min distance: 50
- Rounds: 200
- Instruction set: Redcode '94 Draft

## Results (Top 5)

1. Tornado 4 (Beppe Bezzi) - 4005 pts
2. Silver Talon 1.3 (Edgar) - 3814 pts
3. No Ideas (Ilmari Karonen) - 3715 pts
4. traumatic smurf (Björn Günzel) - 3688 pts
5. Phantasm 50 (Robert Macrae) - 3588 pts
