# Redcode Maniacs Tournament (1998) - Round 4 Components

This directory contains the components provided for Round 4 of the Redcode Maniacs Tournament.

## Components

- **[Carbonite](./carbonite.red)** by Christian Schmidt (Bomber)
- **[Mini He Scans Alone](./mini_hsa.red)** by Paul Kline (Scanner)
- **[Timescape (1.0)](./timescape.red)** by Juha Pohjalainen (Paper)

## Tournament Rules (Round 4)

- Core size: 8000
- Max processes: 8000
- Cycles: 80000
- Max entry length: 100
- Min distance: 100
- Rounds: 200
- Instruction set: Redcode '94 Draft
- Idea: Design a p-switcher using the provided components.
