# Redcode Maniacs Tournament (1998) - Round 3 Warriors

This directory contains a selection of warriors from Round 3 of the Redcode Maniacs Tournament.

## Warriors

- **[Seven-Eleven](./macrae.red)** by Robert Macrae (1st place)
- **[HeScans T](./kline.red)** by Paul Kline (2nd place)
- **[HSA (no decoy)](./moore.red)** by David Moore (4th place)
- **[Sorry Paul for stealing your code :-)](./bezzi.red)** by Beppe Bezzi (3rd place)

## Tournament Rules (Round 3)

- Core size: 8000
- Max processes: 8000
- Cycles: 80000
- Max entry length: 100
- Min distance: 100
- Rounds: 200
- Instruction set: Redcode '94 Draft
- Battle method: Each warrior fights ten specified benchmark warriors.

## Results (Top performers)

1. Seven-Eleven (Robert Macrae) - 4033 pts
2. HeScans T (Paul Kline) - 3918 pts
3. Sorry Paul... (Beppe Bezzi) - 3681 pts
4. HSA (no decoy) (David Moore) - 3672 pts
