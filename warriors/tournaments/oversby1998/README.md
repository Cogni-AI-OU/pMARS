# Oversby Autumn 1998 Corewar Tournament

This directory documents the Oversby Autumn 1998 Corewar Tournament
(Nov 1998 - Mar 1999).

Reference: https://corewar.co.uk/oversby/index.htm

## Summary
- Overall winner: Joonas Pihlaja
- Runner-up: Christian Schmidt
- Third place: Robert Macrae
- Highest-ranked novice: W. F. B.

## Round highlights
- Round 1: David Moore won with `Recycled Bits`
- Round 6: Christian Schmidt won
- Round 7: John Metcalf won
- Round 8: Joonas Pihlaja won the final round and the tournament

## Regression fixture
The automated test for this tournament uses a representative archived
warrior subset from the repository to keep the simulation deterministic
and fast while preserving the historical round 1 parameter set.
