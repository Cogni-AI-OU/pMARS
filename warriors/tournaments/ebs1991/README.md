## EBS ICWS Qualification Tournament (Nov 1991)

The Electronic Branch Section held an ICWS Qualification Tournament in November 1991 with the top warriors advancing to the [1991 ICWS Tournament](../icwt1991).

Programs competed in a one-on-one round robin with [XTC](xtc.red) by Stefan Röttger taking first place. Other participants included [Quarter](quarter.red), [Vlad](vlad.red), [DAC](dac.red), [Mr. Nasty](mrnasty.red), and [Dervish](dervish.red).

For full results, see [RESULTS.md](RESULTS.md).
