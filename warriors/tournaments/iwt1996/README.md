## Tournament: Intelligent Warrior Tournament v1.0 (Mar 1996)

The aim of this tournament was to eliminate all opponents without destroying the Redcode Operating System ([RedOS](8000/redos.red)).

Kurt Franke claimed victory with his handshaking vampire, [System Trap](8000/systemtrap.red).

### Rules

- Coresize: 8000
- Max processes: 8000
- Cycles: 80,000
- Rounds: 200
- RedOS: A simulated operating system residing in core.
