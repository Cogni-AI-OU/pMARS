# Core War Tournament Weekend 2025

The Core War Tournament Weekend returned to the Retro Computer Festival in Cambridge, UK on 15–16 November 2025.

Full results and information can be found at [corewar.co.uk/tournamentweekend2025.htm](https://corewar.co.uk/tournamentweekend2025.htm).

- ['94 Tournament (Sunday)](./94/)

## Demos

The festival featured demos of genetic programming, optimization techniques, and related programming games on several SBCs including a Milk-V Mars, a Radxa X4, and an Orange Pi RV2.
