## Tournament: Second International Core Wars Society Tournament (Nov 1987)

This tournament was held as part of the Core War community competitions at The Computer Museum on 8th November 1987. Over 140 entries were received.

### Rules
- **Standard**: CWS'86
- **Coresize**: 8192
- **Processes**: 64
- **Entry length**: 512
- **Points**: 3 for win, 1 for tie
- **Cycles**: 50,000
- **Rounds**: 3
