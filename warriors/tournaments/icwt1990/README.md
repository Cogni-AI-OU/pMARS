## Tournament: Fifth International Core Wars Society Tournament (Dec 1990)

The Fifth International Core Wars Society Tournament was held in December 1990. It was the first ICWS tournament to use the CWS'88 standard. 19 authors competed with a total of 26 warriors in a round-robin format.

### Tournament Settings
- **Standard:** CWS'88
- **Core size:** 8192
- **Maximum processes:** 64
- **Entry length:** 64
- **Points:** 3 for a win, 1 for a tie
- **Cycles:** 125,000
- **Rounds:** 6
