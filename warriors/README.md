# ICWS Warriors

This directory contains a collection of warriors for the different International Core War Standards (ICWS).

## Standards Overview

- **ICWS'88**: The original 1988 standard. 8000 cells core, no P-space, limited opcodes and modifiers.
- **ICWS'94**: The 1994 draft standard. Adds modifiers, new addressing modes, and P-space.
- **94nop**: ICWS'94 without P-space (Private Memory Space). This is the most common competitive standard.
- **94LP (Limited Process)**: ICWS'94 rules but with a very small limit on the number of processes (usually 8).
- **94Multi**: Multi-warrior (Battle Royale) battles where more than two warriors compete simultaneously.
- **Tiny**: ICWS'94 rules but on a much smaller core (800 cells).
- **Nano**: Even smaller core (80 cells).
- **88Tourney**: ICWS'88 rules but with tournament-specific settings (e.g., core size 8192).
